# Spawn vs. Cenobites: The Unclaimed

A complete 32-page supernatural horror fan comic with a cover, 96 panels, readable transcripts and a responsive page-turning reader.

Read at https://itsmenuttybutty.github.io/the-unclaimed/

Open index.html locally or use any static web host. All artwork and code are included; no backend, API keys, build step or dependencies are required. Phones use single pages; desktop supports spreads. Use swipe, arrows, page browser, fullscreen and fit/full-resolution zoom. Reading progress saves on the current device where browser storage is available.

The-Unclaimed-Full-Script.md contains the complete story and panel script. assets/page-00.png is the cover; page-01.png through page-32.png are the story pages.

This is an unofficial crossover fan comic, created for Nutty with ChatGPT and AI-generated illustrations. Spawn was created by Todd McFarlane; Hellraiser and its Cenobites were created by Clive Barker. Character rights belong to their respective owners. This fan story is not official continuity.

This folder is independent of the existing homepage at the repository root.
