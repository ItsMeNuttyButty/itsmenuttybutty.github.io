# The Last Question

The revised John Kramer × Pinhead comic: a cover and 12 illustrated pages, with page navigation, scroll mode, zoom, transcripts and saved reading progress.

Read at https://itsmenuttybutty.github.io/the-unclaimed/

This replaces The Unclaimed at its original address. The previous comic remains recoverable in Git history. Project Duel at the repository root is unchanged.

Static HTML/CSS/JavaScript; no build step or backend. Serve this directory locally with `python -m http.server 8000` or use GitHub Pages.

Original, non-canon fan crossover created with Nutty and AI assistance. Character rights belong to their respective owners.
